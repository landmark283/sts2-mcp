# 通用构筑框架（STS2）

## 先看结论

一套能稳定通关的卡组，至少要回答五个基础问题：

1. 攻击端：我怎么稳定造成伤害，怎么处理单体和群体？
2. 防御端：我怎么挡住伤害，怎么应对爆发回合？
3. 过牌：我怎么更快摸到关键牌，减少卡手？
4. 回费：我怎么把强牌打出去，而不是捏在手里？
5. Buff / Scaling：战斗拉长以后，我靠什么变强？

如果这五项里有两项长期缺失，卡组通常会在中后期崩掉。

## 五个基础类别

### 攻击端

- 这是最直观的一类，但不能只看面板伤害。
- 需要同时考虑三件事：
- 前期即时伤害够不够，能不能抢死威胁目标。
- 有没有 AOE 或多目标处理能力。
- 有没有后期终结能力，避免 Boss 战只能刮痧。

攻击端常见问题：

- 只有单体爆发，没有 AOE，遇到多怪或召唤战就崩。
- 只有小刀和零碎输出，没有收尾能力，长战伤害不够。
- 只拿慢热终端牌，前中期清怪速度太慢，血量被白白磨掉。

### 防御端

- 防御不等于“多拿防御牌”。
- 真正要看的，是你有没有稳定跨过高伤害回合的方法：
- 直接格挡
- 虚弱、敏捷增加、敌方力量降低、
- 回复、护甲、延迟结算
- 快速斩杀来减少对方输出回合

防御端常见问题：

- 平时能挡 8 到 12，遇到 25+ 或 40+ 爆发就直接穿。
- 一味删防御，导致前期普通战都不稳定。

### 过牌

- 过牌决定的是“这套牌到底像不像同一套牌”。
- 过牌越稳定，越容易找到核心组件、凑连招、避开坏抽。
- 过牌包括抽牌、检索、弃牌过滤、回手、保留、牌堆操控。

过牌端常见问题：

- 核心牌很多，但全都摸不到。
- 伤害、防御、Buff 各拿一点，结果每回合都东一张西一张。
- 为了追求厚度和上限，导致核心组件实际命中率越来越低。

### 回费

- 回费不是只有“+1 能量”。
- 一切能提高当回合出牌总量的东西都算回费体系：
- 直接获得能量
- 返还能量
- 降费
- 0 费连锁
- 保留到下回合打大回合

回费端常见问题：

- 手牌很强，但能量不够，永远打不完。
- 过牌很猛，结果越抽越打不出去。
- 拿了很多高费终端，却没有任何启动回合。

### Buff / Scaling

- Buff 是“让后续回合比前一回合更强”的东西。
- 可以是力量、敏捷、毒、能力牌、姿态、计数器、成长型武器，也可以是某种稳定滚雪球引擎。
- 中后期 Boss 战尤其依赖这部分。

Buff 端常见问题：

- 只会打平推伤害，战斗一长就明显疲软。
- 只有成长，没有前期强度，导致没撑到发力回合就掉太多血。
- 拿了太多重复 Buff，启动过慢，反而拖垮卡组。

## 构筑的正确顺序

### 第一阶段：补齐底线

- 前期最重要的是把五项基础功能补到“能用”，不是立刻做梦幻构筑。
- 这时拿牌优先级通常是：
- 能直接提升当前胜率的高质量单卡
- 能填补空缺类别的牌
- 能解决近期精英/Boss 的牌

### 第二阶段：确定核心包

- 当你的牌组已经有大致方向后，就该收缩选择范围。
- 核心包通常由三部分组成：
- 主输出包
- 主防御包
- 循环支持包

这时要开始学会跳过奖励牌。不是所有稀有牌都值得拿。

### 第三阶段：压缩与提纯

- 中后期比“再多一张强牌”更重要的，往往是“少一张没用的牌”。
- 只要构筑主轴已经明确，默认优先级会逐渐变成：
- 删除废牌
- 升级核心
- 补齐关键短板
- 最后才是继续增厚

## 拿牌原则

每次看到奖励牌，都先问这五个问题：

1. 这张牌补的是哪一个类别？
2. 它是解决当前短板，还是只是“看起来很强”？
3. 它是不是比我牌组里最差的牌明显更好？
4. 它会不会让我的循环更慢、更厚、更依赖运气？
5. 下一个精英或 Boss 会不会因为我拿了它而更好打？

如果这五个问题都答不好，跳过通常比硬拿更好。

## 删牌原则

- 商店删牌通常是最稳定的强度来源之一。
- 默认先删最差的基础攻击，因为它们最容易在中后期变成白板。
- 什么时候优先删基础防御：
- 你已经有更高质量的格挡来源。
- 你的防御主要靠减伤、能力、控制或回复。
- 当前主要问题是抽到太多低质量防御，打不出节奏。

不要机械地“先删完所有打击再说”。如果当前牌组输出已经够，反而防御端更薄，删防御也可能是对的。

## 关于牌组厚度

- 精简通常是对的，但不要把“牌组越薄越好”理解成死规则。
- 真正重要的是：核心组件的命中率，和每次洗牌后的平均手牌质量。
- 一般来说：
- 没有强过牌时，过厚会明显稀释核心牌。
- 有强过牌和回费时，可以容纳更多功能牌。
- 如果卡组里废牌很多，即使只有 20 张也会显得臃肿。

## AOE 是必修课

- 不少牌组输不是因为单体伤害不够，而是清不掉两到四个怪。
- 到第一幕中后段前，最好已经有至少一种可靠的 AOE 或多目标处理方法。
- AOE 不一定非得是纯群伤，也可以是：
- 低费连打
- 连续点杀
- 召唤物清理
- 能同时压多个目标的 debuff

## HP 管理

- 血量不是“留着不用”，也不是“可以乱花”。
- 合理掉血换的是路线收益、精英奖励、事件收益、升级次数。
- 不合理掉血，是在普通战里因为构筑缺口被动挨打。

## 一套健康牌组的样子

当你准备进中后期时，一套健康牌组通常具备这些特征：

- 有明确主输出，不靠所有牌一起刮。
- 有稳定防御，不怕单个坏抽直接暴毙。
- 有过牌或检索，能较快摸到关键牌。
- 有回费或降费手段，强牌能在关键回合打出去。
- 有 Buff 或成长能力，Boss 战不会越打越弱。
- 有处理多目标和高爆发回合的预案。

## 常见误区

- 每场战斗后都拿一张牌，结果核心越来越难摸。
- 看到金卡就拿，不看是否契合主轴。
- 只围绕“流派名”拿牌，不看五个基础类别是否齐全。
- 只有输出和过牌，没有像样的防御与爆发回合答案。
- 为了做梦幻后期构筑，前期拿太多慢牌，没撑到成型就死了。
