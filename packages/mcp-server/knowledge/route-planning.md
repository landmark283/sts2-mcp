# 路线规划（STS2）

## 核心原则

- 路线不是找“最赚”的节点，而是找“当前牌组能安全吃下的收益”。
- 规划路线前，先判断牌组当前最缺什么：输出、格挡、AOE、过牌、回费、升级、删牌、金币。
- 血量是资源，但不是可以随意挥霍的资源。为精英、Boss、关键商店保血，比在普通战里多拿一点金币更重要。
- 问号、商店、篝火都很强，但前提是你有资本去吃它们。弱牌组先补稳定性，强牌组再追求上限。

## 开局奖励

- 优先选能立刻改变路线质量的东西：能量、强遗物、优质稀有卡、直接删牌。
- 如果奖励只会让卡组变厚，但不能解决近期战斗问题，宁可不选。
- 开局奖励决定前 5 层节奏。拿到爆发型奖励可以多打一场精英；拿到慢热型奖励要主动避险。

## 地图节点优先级

### 战斗

- 前几层普通战通常必须打，因为金币、卡牌奖励、药水都会决定成型速度。
- 如果牌组还没有像样的输出或格挡，前期普通战的优先级高于问号。
- 连续三场以上普通战很危险，除非中间有商店、篝火或当前牌组已经明显碾压。

### 精英

- 只有在满足下列大部分条件时才主动找精英：
- 当前血量健康，并且打完后仍有修复手段。
- 牌组已经有明确的前排输出方案，不会被拖入长战。
- 至少有一个可靠的防御回合，或能用药水/爆发直接抢节奏。
- 有 AOE、清小怪能力，或者能快速点杀威胁目标。
- 路线允许精英后接篝火、商店或较安全的节点。

### 问号

- 问号的价值在“用更低代价换资源”，不是无脑高于普通战。
- 当前血量低、牌组弱、又急需稳定收益时，普通战往往比问号更可控。
- 当你已经有基本战斗力，且需要删牌、遗物、事件专属收益时，问号价值会明显上升。

### 商店

- 商店最重要的功能通常不是买一堆东西，而是删掉最差的牌。
- 默认删牌优先级：纯拖节奏的基础攻击 > 纯拖节奏的基础防御。
- 只有在出现真正改变构筑质量的核心牌、核心遗物时，才应压过删牌。
- 钱不够时，优先保证“删牌或关键购买”其中之一，不要把金币散花式花光。

### 篝火

- 默认优先升级，而不是休息；但前提是升级后不会马上死。
- 能让核心引擎启动的升级，通常比普通数值升级更值钱。
- 如果下一个高风险节点是精英或 Boss，且当前血量不足以承受一次坏抽，休息优先级立刻上升。

## 分幕路线思路

### 第一幕

- 目标是补齐基础功能，不是强行锁死流派。
- 第一幕结束前，理想状态是：
- 至少有一张像样的 AOE 或多目标处理手段。
- 至少有一套能稳定挡下中高额伤害的方案。
- 至少有一张能提升循环质量的过牌或回费牌。
- 第一幕精英通常值得争取 1 次，前提是牌组确实过关，不要为了“理论最优”硬撞。

### 第二幕

- 第二幕开始后，路线应更多围绕“强化已经成型的核心包”。
- 如果牌组仍然靠基础打击/防御过活，优先找商店、普通战和篝火，不要硬刷高风险节点。
- 第二幕精英是实力检查。没有 AOE、没有持续输出、没有稳定防御时，尽量少碰。

### 后期与荣耀

- 后期路线优先考虑 Boss 适配，而不是节点面板收益。
- 进入荣耀段之前，要问自己两个问题：
- 我能不能处理 40+ 的爆发回合？
- 我的伤害是不是只能靠慢慢磨？
- 如果这两个问题答案都不好，优先补强短板，不要再贪边际收益。

## 路线决策清单

每次看图时，按这个顺序判断：

1. 我这套牌现在最缺什么？
2. 下一个大风险点是谁，普通战、精英还是 Boss？
3. 现有血量和药水能不能覆盖一次坏抽？
4. 这条路线能不能提供删牌、升级或关键购买？
5. 我是否已经有 AOE、稳定格挡、回费/过牌中的至少两项？

## 常见错误

- 每层都按“节点稀有度”选，不按当前牌组需求选。
- 明明还缺基础生存，却为了赌收益连撞精英。
- 商店见到金卡就买，结果错过删牌和关键遗物。
- 血量已经危险还继续规划长战路线，导致后面没有任何容错。
