# 事件决策（STS2）

## 查询入口

- 适合回答的问题：
- 这个事件该保血、拿收益，还是直接走保守线？
- 事件给出的收益，是否真的补了当前短板？
- 代价是血量、金币、诅咒、删牌还是随机性，我现在付不付得起？
- 这种事件是否应该在当前阶段主动去找更多问号？

## 事件判断框架

### 第一步：先看代价类型

- 掉血：问自己这点血是不是会影响下一个精英、Boss、连续战斗。
- 金币：问自己是否会影响最近一次商店的删牌或关键购买。
- 卡组质量：问自己是变强、变薄，还是只是变乱。
- 随机性：问自己当前局面需不需要稳定，而不是需不需要赌高上限。

### 第二步：再看收益类型

- 立即战力
- 长期成长
- 经济收益
- 删牌或压缩
- 稀有资源，例如遗物、特殊牌、事件专属收益

### 第三步：最后看近期压力

- 如果下一到三层就有高风险战，优先选稳定解。
- 如果当前血量低、牌组弱，问号不应该无脑当成“高收益节点”。
- 如果当前牌组已经稳，才更适合把事件当成高上限节点。

## 四类高频事件

### 血量换收益

- 只有当收益能立刻改善牌组质量或路线质量时才值得交血。
- 低血线时，血量的价值会远高于金币或随机增益。
- 如果这次掉血会逼你下个营火休息，那实际代价往往比表面更高。

判断要点：

- 掉血后还能不能接精英或 Boss。
- 收益是否解决当前关键短板。
- 是否只是为了贪未来收益而牺牲当前稳定性。

### 删牌 / 变牌 / 压缩

- 这类事件通常非常强，因为它们直接影响抽牌质量。
- 但要看它删掉的是不是你现在真正最差的牌。
- 随机变牌的价值，取决于你是否能接受构筑方向被打乱。

判断要点：

- 当前最差的牌是不是确实该尽快移除。
- 变牌结果若偏离主轴，你还能不能承受。
- 这次操作会不会让近期战斗更稳定，而不是更花。

### 赌收益 / 翻牌 / 占卜

- 这类事件的关键不是“理论最赚”，而是“当前是否值得承受波动”。
- 当你很稳时，可以接受一定随机性来换上限。
- 当你很虚时，随机收益经常不如确定收益。

判断要点：

- 当前牌组是否已经有容错。
- 收益池里是否存在你非常需要的东西。
- 失败结果是否会立刻拖垮当前路线。

### 诅咒 / 负面交换

- 诅咒不只是少一张手牌，它会持续污染抽牌与商店节奏。
- 如果近期没有删牌窗口，诅咒代价要按放大后的版本去算。
- 除非收益极高，否则不要轻易拿长期负担换一次性收益。

判断要点：

- 最近有没有稳定删牌机会。
- 当前牌组是否已经够薄，能承受额外污染。
- 收益是否高到足以覆盖整局期望损失。

## 问号路线什么时候更值钱

- 已有基本战力，且更需要删牌、遗物、事件专属资源时。
- 当前普通战收益边际下降，而事件有潜在高收益时。
- 你对随机性有足够容错，并且血量允许试错时。

## 问号路线什么时候该降级

- 当前牌组太弱，需要稳定卡牌奖励和药水。
- 当前血量已经不支持再吃随机代价。
- 你接下来最需要的是可控收益，而不是波动。

## 常见错误

- 把问号默认当成高于普通战的节点。
- 只看事件上限，不看血量、金币、删牌窗口和近期风险。
- 明明卡组还没稳，就频繁选择高波动选项。
- 为了所谓“稀有收益”接受长期诅咒，结果后面没有机会修复。
