# 遗物决策（STS2）

## 查询入口

- 适合回答的问题：
- 这件遗物是立刻变强，还是只是后期收益？
- 为了这件遗物，路线要不要多打一场精英或改走商店？
- 它补的是输出、防御、经济、循环还是成长？
- 它和当前牌组、当前血线、当前金币之间有没有冲突？

## 先做四步判断

1. 它改变的是当前战力，还是只是未来上限。
2. 它补的是当前短板，还是强化已经过剩的部分。
3. 它是否要求你改变拿牌、删牌、路线或出牌习惯。
4. 为了拿到它，你要付出的代价是不是太高。

## 四类高频遗物价值

### 立即战力型

- 这类遗物最适合血量紧、近期有精英或 Boss 压力的时候。
- 价值来自“下一场战斗立刻变简单”，不是账面收益。
- 如果当前牌组只是缺一口气，它们通常比慢热成长型更优先。

判断要点：

- 能不能立刻改善首轮输出或防御。
- 能不能降低坏抽惩罚。
- 能不能让药水、升级、关键牌更容易撑到高风险战。

### 经济型

- 金币、删牌、商店质量、掉落质量相关的遗物都属于这一类。
- 这类遗物的价值高度依赖路线和商店距离。
- 如果接下来很久都见不到商店，纯经济收益会打折。

判断要点：

- 还能不能及时转化成删牌或关键购买。
- 当前牌组是不是已经稳定到能把经济优势兑现出来。
- 会不会因为贪经济而错过保血路线。

### 循环型

- 这类遗物提升的是过牌、回费、起手质量、保留质量或出牌总量。
- 它们在“牌本身已经够强，但总是打不出来”的卡组里价值很高。
- 如果牌组里还没有高质量出牌目标，循环遗物的收益会被高估。

判断要点：

- 当前是否常出现“手牌很强但费用不够”。
- 当前是否常出现“核心牌摸不到”。
- 新增循环后，牌组是不是有足够多的落地点。

### 成长型

- 这类遗物通常在 Boss 战、长战、荣耀段最强。
- 它们不是前期不能拿，而是前提必须是底线已经稳住。
- 如果普通战都经常掉血，先补底线比先追上限更重要。

判断要点：

- 当前普通战是否已经稳定。
- 是否已经有一套能把成长收益兑现出来的主轴。
- 下一层 Boss 或精英会不会在成长展开前就把你打死。

## 路线联动

### 什么时候为遗物改路线

- 遗物能明显改变你对精英、商店、营火的承受能力时。
- 遗物能让某种短板直接消失，例如起手、防御、AOE、能量。
- 拿到后，后续两到三层就能立刻兑现收益时。

### 不该为遗物改路线的时候

- 当前血量已经不支持额外风险。
- 遗物只是泛强，但不能解决当前最致命问题。
- 你为了它要连续穿过多个高风险节点，而且中间没有恢复点。

## 商店联动

- 商店最常见的高价值动作仍然是删牌。
- 如果遗物只是“让你更想买更多牌”，而不是提升删牌质量，要谨慎。
- 经济遗物的价值，应按“下一次商店能兑现多少”来算，不按理论总收益来算。

## 营火联动

- 会改变升级价值的遗物，要重新评估营火优先级。
- 会改善续航或坏抽容错的遗物，能让升级窗口变多。
- 会放大战斗爆发的遗物，通常更值得配合路线去争取篝火后精英。

## 常见误判

- 把所有稀有遗物都当成无脑高优先级。
- 只看长期收益，不看当前血量和近期战斗压力。
- 明明缺的是稳定性，却为了上限遗物去走贪线。
- 拿到循环遗物后继续无节制增厚牌组，结果收益被自己稀释。
