# 卡牌评价框架（STS2）

## 这不是固定 Tier List

- 不同角色、不同遗物、不同路线下，同一张牌的价值可能差很多。
- 比起背 S/A/B 排名，更重要的是判断一张牌在当前卡组里扮演什么角色。
- 评价卡牌时，先看“它解决什么问题”，再看“它本身强不强”。

## 五类基础职责

所有卡牌，最终都可以按职责放进这五类中的一类或多类：

1. 攻击端
2. 防御端
3. 过牌
4. 回费
5. Buff / Scaling

如果一张牌在你牌组里无法清晰回答“它负责哪件事”，那它往往就是可疑选择。

## 卡牌评价顺序

### 第一步：看当前缺口

- 当前最缺的是清怪、挡伤、过牌、能量还是成长？
- 如果牌组连基本生存都不稳定，再华丽的后期卡都应该降级。
- 如果伤害已经充足，就不要继续拿只能锦上添花的输出牌。

### 第二步：看落地速度

- 这张牌是拿到就能解决问题，还是要 3 张以上配合才工作？
- 前期更看重裸拿就有价值的牌，中后期才更能接受体系件。
- 需要一整套支持的牌，默认应该比“单卡就强”的牌更谨慎。

### 第三步：看循环代价

- 这张牌会不会让卡组更厚、更慢、更容易坏抽？
- 高费牌、慢热牌、条件牌都会抬高循环成本。
- 如果你没有足够过牌或回费，卡面再强也可能只是纸面强。

### 第四步：看近期战斗

- 下一个精英、Boss、事件战会不会因为这张牌明显更好打？
- 如果不能改善近期最关键的对局，它的优先级就应该下降。

## 不同职责的拿牌逻辑

### 攻击端

优先拿的情况：

- 当前单体伤害不够，连普通怪都要拖多个回合。
- 缺少 AOE 或多目标处理手段。
- 缺少 Boss 终结手段。

降级的情况：

- 牌组已经有足够输出，但防御、过牌、回费仍有明显缺口。
- 新牌只是数值更高，却没有带来新的战斗答案。

### 防御端

优先拿的情况：

- 经常只能硬吃伤害。
- 面对 20+ 以上攻击回合明显不稳。
- 当前防御主要靠基础防御牌，质量偏低。

降级的情况：

- 牌组已经有稳定挡伤方案，再拿同类低质量防御只会拖慢进攻。

### 过牌

优先拿的情况：

- 核心牌摸不到。
- 手里常有多余费用，却没有可打的高质量牌。
- 经常因为坏抽直接掉血。

降级的情况：

- 过牌收益很高，但没有对应的费用和落地牌，导致只是在空转。

### 回费

优先拿的情况：

- 常出现“手里都是好牌但打不完”。
- 你已经有足够多的过牌和高质量出牌目标。
- 牌组开始依赖大回合、连锁回合或高费终端。

降级的情况：

- 牌组里可支配的高质量牌太少，回费只会让手牌更空。

### Buff / Scaling

优先拿的情况：

- 普通战能赢，但 Boss 战明显乏力。
- 伤害、防御都会随着战斗拉长而掉队。
- 当前主轴已经比较清晰，只差一个长期发动机。

降级的情况：

- 前期还没站稳，就先拿了一堆慢热成长牌。
- 成长组件过多，导致启动回合太慢。

## 什么时候该跳过奖励牌

- 三张都不能补当前缺口。
- 三张都只是“强牌”，但会让牌组更厚。
- 三张都与当前主轴无关，且近期战斗压力不允许你贪后期。
- 牌组已经足够成型，现在更需要删牌和升级。

跳过奖励牌不是亏，而是在保护抽牌质量。

## 商店与删牌对评价的影响

- 如果你接下来很快能删牌，就可以更放心地拿一张短期补洞牌。
- 如果近期没有删牌机会，拿牌就要更克制，因为每张牌都会在卡组里待很久。
- 商店里看到“关键遗物或关键牌”之外，删牌常常是最强选项。

## 关于基础牌

- 基础攻击通常最容易在中后期掉队，因此常是首批删除对象。
- 基础防御并不总是更差，是否删除取决于你的真实防御质量。
- 不要因为“攻略都说先删打击”就机械执行。当前牌组若极度缺防，删防御反而可能更差。

## 快速判断模板

每次看到一张牌，快速回答：

1. 它属于哪一类职责？
2. 它能补我当前最痛的缺口吗？
3. 它需要多少支持才能发挥？
4. 它会不会拖慢我的循环？
5. 如果现在拿它，下一个精英或 Boss 是否更好打？

如果只能回答“这张牌看起来强”，那通常还不够构成拿牌理由。
