# 敌人与意图模式（STS2）

## 先读意图，再分类敌人

基础意图可以先按下面理解：

- 攻势：本回合要打你，数字就是需要处理的伤害。
- 策略：本回合更偏向 debuff、塞牌、控场。
- 强化：本回合在为后续回合蓄力。
- 防御：本回合更多是在抬格挡或拖时间。
- 召唤：本回合会增加行动体或制造额外压力。

真正关键的不是看字面，而是判断这只怪属于哪一种威胁模型。

## 五种高频威胁模型

### 1. Debuff 型

特点：

- 不一定马上打很痛，但会快速削弱你的长期战斗力。
- 常见表现是减力量、减敏捷、塞状态牌、上脆弱或虚弱。

处理原则：

- 默认优先级很高，尤其是会永久或长时间削弱你的敌人。
- 如果你是依赖连打、力量或循环的构筑，这类怪的威胁会被放大。

已知例子：

- 缩小甲虫：不断压低你的输出，拖久了会让后续所有战斗步骤都变差。

### 2. 成长型

特点：

- 前几回合看着一般，但不及时处理会指数级恶化。
- 常见表现是加力量、加层数、每回合提高伤害或收益。

处理原则：

- 能抢死就抢死，不能抢死就必须想办法减伤或打断节奏。
- 这类敌人最怕爆发和控制，不怕慢慢磨。

已知例子：

- 毛绒伏地虫：多次强化后伤害会迅速失控。
- Byrdonis：回合越长越危险。

### 3. 召唤型 / 人海型

特点：

- 自己不一定最痛，但会把战场变成多目标压力测试。
- 会放大你 AOE 不足的问题。

处理原则：

- 先判断“召唤体死后是否还会继续给你压力”。
- 有些局面应该秒掉召唤核心，有些局面则要先清小怪保血。
- 如果牌组没有 AOE，就必须提前规划点杀顺序。

已知例子：

- 分裂、召唤、铺场类精英和 Boss。
- Phrog Parasite 一类敌人会把单体构筑拖进非常差的节奏。

### 4. 护甲 / 减伤 / 伤害上限型

特点：

- 不会让你瞬间暴毙，但会惩罚纯爆发思路。
- 常见表现是每回合损失上限、首段伤害减免、多层护甲、每 hit 只掉 1。

处理原则：

- 需要持续输出、回合管理、稳定格挡，不能只赌一手大招。
- 多段攻击、资源滚雪球、持续 debuff 往往比纯大数字更好。

已知例子：

- 带伤害上限或减伤机制的精英、Boss。

### 5. 爆发检查型

特点：

- 平时看起来可控，但会在特定回合打出极高伤害。
- 这是后期和 Boss 最常见的杀人方式。

处理原则：

- 进入战斗前就要知道自己有没有能力处理 30+、40+ 的单回合压力。
- 药水、保留牌、减伤牌和大回合资源都要优先留给这些回合。

已知例子：

- 本次实战中，荣耀 Boss `实验体 #C8` 第三形态有 45 点单次高伤回合。

## 实战识别顺序

每次开战后，按这个顺序识别敌人：

1. 这只怪是在现在杀你，还是在两回合后杀你？
2. 它是靠 debuff、成长、召唤、减伤还是大招赢？
3. 我的牌组最怕它的哪一种手段？
4. 我这一回合最该做的是击杀、减伤、铺成长，还是保资源？

## Act 1 常见压力测试

- 缩小甲虫 + 毛绒伏地虫：一个削你输出，一个滚雪球增伤。若没有快速击杀能力，很容易被普通战打残。
- 沉睡起手的精英：适合先铺能力或资源，但别贪到第二回合爆发接不住。
- 多单位精英：检验你 AOE 和点杀切换的能力。

## 给卡组构筑的反馈

如果你经常输给某种敌人模式，说明构筑里缺的是对应答案：

- 输给 Debuff 型：缺爆发、缺优先击杀能力。
- 输给成长型：缺中前期输出节奏。
- 输给召唤型：缺 AOE 或多目标规划。
- 输给减伤型：缺持续输出和战斗耐久。
- 输给爆发检查型：缺高质量防御、减伤、药水管理或阶段预案。
